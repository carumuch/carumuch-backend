# Bidding Legacy Guide

## 적용 범위

이 지침은 `src/main/java/com/carumuch/capstone/bidding` 이하에서 작업할 때 우선 적용합니다.

이 영역은 레거시 구조 유지보수 대상으로 봅니다.

---

## 작업 원칙

1. 변경은 최소 범위로 제한합니다.
2. 기존 API, 응답 형식, 연관 도메인 흐름의 호환성을 우선합니다.
3. 레거시 구조를 새 코드의 기준으로 삼지 않습니다.
4. 신규 설계가 필요하면 현재 컨텍스트 안에서만 국소적으로 정리합니다.

---

## 주의 사항

- 입찰 상태 변경, 권한 확인, 조회 조건은 회귀 위험이 큰 지점으로 보고 먼저 확인합니다.
- 레거시 서비스가 커 보이더라도 이번 변경과 무관한 메서드 분리는 하지 않습니다.
- 테스트가 부족하면 최소한 핵심 분기와 권한 흐름은 설명 가능해야 합니다.
