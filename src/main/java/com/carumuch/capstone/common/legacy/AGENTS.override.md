# Common Legacy Guide

## 적용 범위

이 지침은 `src/main/java/com/carumuch/capstone/common/legacy` 이하에서 작업할 때 우선 적용합니다.

이 영역은 여러 레거시 모듈이 공유하는 호환성 계층입니다.

---

## 작업 원칙

1. 변경 전에 어떤 레거시 모듈이 이 코드를 사용하는지 먼저 확인합니다.
2. 공통 응답, 예외, 유틸 변경은 파급 범위를 설명할 수 있을 때만 수행합니다.
3. 한 모듈 편의를 위해 공통 레거시 규약을 쉽게 바꾸지 않습니다.
4. 신규 공통화가 필요하면 우선 비레거시 `common` 쪽이 더 적절한지 검토합니다.

---

## 주의 사항

- 예외 포맷, 응답 래퍼, 인증 보조 로직 변경은 회귀 가능성이 높습니다.
- 레거시 의존을 줄이는 방향은 좋지만, 이번 변경 범위를 넘는 전면 이동은 하지 않습니다.
