# Community Legacy Guide

## 적용 범위

이 지침은 `src/main/java/com/carumuch/capstone/community` 이하에서 작업할 때 우선 적용합니다.

이 영역은 레거시 구조 유지보수 대상으로 봅니다.

---

## 작업 원칙

1. 변경은 요청된 범위에 한정합니다.
2. 관련 없는 구조 개선이나 전면 리팩터링은 하지 않습니다.
3. 기존 동작 보존을 우선합니다.
4. 새 기능이 필요하더라도 레거시 관례를 다른 컨텍스트로 전파하지 않습니다.

---

## 주의 사항

- `common.legacy` 의존이 있으면 응답 규약과 예외 흐름 영향을 먼저 확인합니다.
- 인증, 권한, 이미지 처리처럼 다른 모듈과 연결된 지점은 회귀 위험을 우선 봅니다.
- 레거시 코드를 건드리더라도 가능한 범위에서는 더 명확한 네이밍과 작은 책임 분리를 선택합니다.
